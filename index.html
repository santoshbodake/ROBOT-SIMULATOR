      Supported VAL/VAL-II-style commands


      MOVE P1 — move to location

      MOVES P1 — straight/Cartesian-style move

      APPRO P1, 50 — approach above/before target

      DEPART 50 — depart from target

      SPEED 30 — speed percentage

      DRIVE J1, 10 — change joint position

      HERE P1 — teach current robot position

      OPENI / CLOSEI — gripper open/close

      WAIT 1 — wait seconds

      WAIT SIG(1) / WAIT SIG(-1) — wait until external input 1 is ON / OFF (use the IN buttons)

      IF SIG(2) JUMP LBL — branch on an input

      SET COUNT = COUNT + 1 — variable assignment

      IF COUNT < 10 JUMP LOOP — conditional jump

      JUMP LOOP — unconditional jump

      LABEL LOOP or LOOP: — label

      SIGNAL 1 — simulate output signal

      TYPE P1 — display location

      STATUS — display robot status

      READY — ready state

      ABORT — stop program

      PAUSE — pause program


      Program structure

      This is an educational simulator. It intentionally does not claim to implement every controller-specific VAL/VAL-II command.
